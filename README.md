# Расписание (Proof-of-Concept)

Учебный проект - веб-приложение для просмотра персонализированного расписания занятий с авторизацией через Яндекс ID.

## 🛠 Стек технологий
* **Backend:** Python, FastAPI
* **Database:** SQLite
* **Frontend:** HTML, CSS, Vanilla JavaScript
* **Auth:** OAuth 2.0 (Яндекс ID)
* **Кеширование:** In-memory cache (TTL 5 минут)

## 🚀 Основные возможности
* Авторизация пользователей через внешний провайдер (Яндекс ID).
* Разделение данных: каждый пользователь видит только свое расписание.
* Кеширование запросов к БД для снижения времени отклика.
* Визуализация расписания в виде недельной сетки.

## ⚙️ Локальный запуск
1. Клонируйте репозиторий.
2. Перейдите в папку `backend` и создайте виртуальное окружение:
   `python -m venv venv`
   `venv\Scripts\activate`
3. Установите зависимости:
   `pip install -r requirements.txt`
4. Создайте файл `.env` по примеру `.env.example` и добавьте свои ключи от Яндекс ID.
5. Инициализируйте базу данных:
   `python seed.py`
6. Запустите сервер:
   `uvicorn main:app --reload`
7. Перейдите по адресу `http://localhost:8000/`.
